🛡️ Anti-Crash va Xavfsizlik Tizimi

Qanday qilib server hech qachon buzilmaydi va qotmaydi?

Grazajon Cloud PaaS serveri klaster va VPS xotirasini himoya qiluvchi kuchli Anti-Crash Watchdog bilan jihozlangan:

  • RAM Limitini Majburiy Nazorat Qilish: Agar biror foydalanuvchining kodi xotirani haddan tashqari ko'p yeb qo'ysa (masalan 150MB dan oshsa), butun tizim qotib qolishidan asrash uchun tizim o'sha bitta botni avtomatik to'xtatadi. Boshqa foydalanuvchilar ishlashda davom etadi.

  • Crash Loop Himoyasi: Agar biror bot to'xtovsiz xato berib qayta yonaversa, CPU qizib ketmasligi uchun avtomatik ravishda orom olish rejimi yoqiladi.
  • DDoS va Brute-Force Himoyasi: Bir soniyada yuzlab urinishlar qilgan shubhali IP manzillar avtomatik cheklanadi.
